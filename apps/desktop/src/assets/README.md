# Pengu Pet Assets

**Owner:** M2 (Suparna Darsi)

- `penguin-default.png` — Static default Pengu sprite (`pengu_idle.png`).
- `pengu/` — Full Pengu pixel-pet sprite and animation pack (14 PNG state sprites + 9 looping GIF animations) used by `PetWindow` to animate `pet.state` (`idle`, `listening`, `thinking`, `executing`, `awaiting_approval`, `completed`, `failed`) and pointer dragging (`pengu_dragged.png`).
